# 겪었던 문제와 해결법

실제 제작(LLM 원리 모션그래픽)에서 부딪힌 것들이다. 비슷한 증상이 보이면 여기부터 본다.

## 렌더링·엔진
- **폰트가 file://에서 깨짐** → 폰트를 base64로 묶은 `fonts.js`를 `FontFace` API로 로드한다(`scripts/build_fonts.py`). 서버 없이 더블클릭해도, 헤드리스 추출에서도 같은 글꼴이 나온다.
- **`cam({x:0, y:0})`가 화면 중앙으로 가 버림** → 예전 엔진은 `o.x || W/2`여서 0이 무시됐다. 템플릿 엔진은 `=== undefined`로 고쳐져 있다. 비슷한 `||` 기본값 버그를 새로 만들지 않는다.
- **Math.random / 누적 상태** → 추출 영상이 떨리거나 뒤로 가기가 틀어진다. `rnd(i)`와 S의 함수만 쓴다.
- **엄청 많은 요소(수천 개 다이얼)를 줌아웃** → 개별로 그리지 말고, 오프스크린 캔버스에 10×10 타일을 만들고 그 타일을 다시 10×10으로 묶는 LOD 이미지(600px)를 단계별로 쓴다. 가장자리에는 비네트.
- **캔버스에 외부 이미지(로고 등)를 그리면 export의 `toDataURL`이 막힘(tainted)** → SVG는 data URI로 만들어 그린다.
- **스텝을 건너뛰는 버전 분기에서 요소가 번쩍임** → 건너뛴 스텝에서 켜지는 요소를 해당 버전에서 명시적으로 끈다.
- **초보자 버전에서 장면의 1번 스텝을 건너뛰면**, 등장 페이드가 2번 스텝 위에서 일어난다. 블록 등장 → 효과 순서가 보이도록 2번 스텝 타이밍을 `sub(p, 0.3, 1)`처럼 뒤로 민다.

## 검수
- 브라우저 미리보기 창은 작고 비율이 달라 세부를 놓친다. **최종 판단은 `node render.mjs snap …`의 1920×1080 PNG를 `contact_sheet.py`로 묶어서** 본다.
- 스냅 폴더에 예전 PNG가 남아 있으면 시트에 섞인다. 다시 찍기 전에 `rm -rf snaps`.
- 미리보기용 정적 서버는 `.claude/launch.json`에 `python3 -m http.server <포트> --directory <폴더>`로 등록한다. 포트가 이미 쓰이면 다른 번호로 바꾼다. `MG.seek(12.5)`로 원하는 위치를 바로 본다.

## 추출(MP4/PPTX)
- Playwright는 `playwright-core` + 시스템 Chrome(`channel:'chrome'`)으로 충분하다. 브라우저를 따로 받을 필요가 없다.
- 1080p60 기준 36스텝 약 4분, 장면 단위(30fps)는 약 2분.
- 다이얼 줌아웃처럼 잔무늬가 많은 장면은 영상이 커진다(26MB). 올릴 곳에 크기 한도가 있으면 해당 파일만 `ffmpeg -crf 24`로 다시 인코딩한다.
- PPTX 자동 재생 XML은 python-pptx가 넣는 '클릭하면 재생' 타이밍을 교체한 것이다. **PowerPoint 실물에서는 검증하지 못했다**(Keynote만 있었음). 결과를 넘길 때 이 점을 알리고, 안 되면 클립을 직접 넣고 재생을 '자동'으로 바꾸라고 안내한다.
- 포스터(재생 전 정지 화면)를 각 클립의 첫 프레임으로 넣으면 슬라이드가 넘어갈 때 튀지 않는다(첫 프레임 = 이전 스텝의 끝 화면).

## 그 밖에 (사용자가 요청할 때만)
- Notion에 영상 넣기: 업로드는 `notion-create-file-upload`에 `content_type: video/mp4`를 명시하고 curl로 POST한다. 단일 업로드는 파일당 20MB가 한도다. **기존 업로드 이미지는 `update_content`로 매칭·삭제할 수 없다**(서명 URL 불일치). 이미지 아래 문단을 기준으로 영상을 끼워 넣고, 이미지는 사용자가 직접 지우게 안내한다.
- 배포: 정적 폴더라 `vercel deploy --prod`면 된다(`.vercelignore`에 `export/`). Cloudflare DNS에 와일드카드 레코드가 있으면 서브도메인에 A `76.76.21.21`, **DNS only(회색 구름)** 레코드를 추가해야 한다. 인증서는 1~2분 뒤 발급된다.
- GitHub 푸시가 `Permission denied (publickey)`면 SSH 키가 없는 것이다. 원격을 HTTPS로 바꾸고 레포 로컬 설정으로 `credential.helper '!gh auth git-credential'`을 쓴다(전역 설정은 건드리지 않음).
