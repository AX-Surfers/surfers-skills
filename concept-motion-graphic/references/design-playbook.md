# 설계 플레이북 — 원리를 장면과 스텝으로 옮기기

## 1. 원천 자료에서 "필수"만 고르기

입력은 보통 세 가지다: (a) 강의 원문(Notion 등)의 해당 섹션, (b) 레퍼런스 영상 분석, (c) 사용자의 요청. 우선순위는 **원문 > 요청 > 레퍼런스**다.

- 원문이 있으면 그 항목 순서가 장면 순서다. 레퍼런스 영상의 모든 내용을 옮기지 않는다. 레퍼런스는 **연출 문법**(비유, 전환, 시각 요소)을 빌려오는 곳이다.
- 항목 하나 = 장면 하나가 기본이다. 한 장면은 2~6스텝.
- 원문에 있는 예시 문장·숫자를 그대로 화면에 쓴다(강의 자료와 영상이 어긋나지 않게). 원문의 비유가 영상으로 표현하기 어려우면(예: "찢어진 대본") 가까운 형태(빈칸이 있는 회의록)로 바꾸고, 그 사실을 사용자에게 알린다. 문서도 같이 고칠지는 사용자에게 묻는다.
- 원문에 없는 사실이나 수치를 새로 넣을 때는 출처가 분명한 것만 넣는다(예: "GPT-3 1,750억 개"). 확신이 없으면 빼거나 묻는다.

## 2. 스토리보드 표 (구현 전에 사용자에게 보여 준다)

| 장면 | 스텝 | 화면에서 일어나는 일 | 자막(한 줄) |
|---|---|---|---|
| 1 다음 단어 예측 | ① | 회의록 카드가 그려짐, B의 답이 비어 있음 | — |
| | ② | 모델 상자 등장, 입출력 화살표 | 문장을 넣으면 **다음에 올 단어**를 예측하는 기계 |
| | ③ | 빛이 들어가고 '고객이'가 튀어나와 빈칸으로 날아감 | |
| | ④ | 점점 빨라지며 단어가 이어 붙음, '반복' 루프 화살표 | 예측한 단어를 붙이고 → 다시 넣고 → **반복** |

스텝 나누기 기준: **발표자가 말을 멈추고 설명할 지점**마다 끊는다. 한 스텝에는 새로운 생각이 하나만 들어간다. 스텝 재생 시간 `d`는 2.4~5.5초가 적당하다. 반복 연출(단어 7개 이어 붙이기, 학습 루프)은 한 스텝 안에서 **점점 빨라지게** 넣는다(가중치 0.8^k로 구간 분할).

## 3. 3Blue1Brown 룩

- 순검정 배경. 흰 글자, 회색 윤곽. 강조색은 한 장면에 1~2개(노랑=핵심/정답 후보, 파랑=데이터 흐름, 초록=정답, 빨강=오답·오차, 분홍=대비되는 두 번째 의미).
- 숫자·수식은 세리프(Computer Modern 계열), 한글 설명은 산세리프.
- 연속성: 요소를 지우고 새로 그리기보다 **이동·변형**시킨다(단어 타일이 날아가 빈칸에 들어감, 3D 블록이 돌며 레이어로 분해, 줌인해서 다이얼 격자로 전환).
- 쓸 만한 연출 문법:
  - 입력(왼쪽) → 블록(가운데) → 출력(오른쪽)의 가로 흐름
  - 확률 막대가 자라고 수치가 올라감
  - 단어 → 세로 대괄호 벡터 변환
  - 관계선(호)이 단어를 잇고 밝기가 맥동함
  - 스케일 줌아웃(1초→1분→…→1억 년, 다이얼 하나→수천억 개)
  - 뽑기 룰렛(하이라이트가 후보 사이를 오가다 감속해 멈춤)
  - 오차 신호가 반대 방향으로 흐르며 다이얼이 돌아감

## 4. 화면 배치 (1920×1080)

- 좌상단 (80, 76): 장면 제목(엔진 자동). 우상단: 로고 자리.
- 하단 y≈990: 자막. 본문 요소는 y 150~900 안에 둔다.
- 가로 3단(입력/블록/출력)일 때: 입력 x 110~800, 블록 중심 x ≈1000~1240, 출력(막대 라벨 오른쪽 끝) x ≈1420~1550. 막대의 최대 폭과 퍼센트 글자가 x 1880을 넘지 않는지 계산한다.
- 글자 크기: 제목 90~100, 본문 문장 38~50, 라벨 24~32, 자막 36~40.

## 5. 대상 청중 말투

비개발자 대상이면 자막은 **짧은 한 문장, 비유 중심**으로 쓴다. 전문 용어는 처음 나올 때 쉬운 말을 앞에 둔다("다이얼 하나 = 숫자 하나 = 파라미터(가중치)"). 수식은 꼭 필요한 한 번만 쓰고 바로 아래에 라벨("다음 단어 / 앞 문장(조건) / 확률")을 단다.

## 6. 초보자 버전을 만들 때 제안할 기준 (사용자와 인터뷰로 확정)

1. 개념이 무거운 장면은 비유 하나로 합치거나 뺀다(예: 트랜스포머+어텐션 → "문장을 통째로 한 번에 본다").
2. 수식 스텝을 뺀다.
3. 전문 용어를 우리말로 바꾼다.
4. 큰 숫자 연출을 한두 개만 남긴다.
5. 전체 구조도(파이프라인) 스텝을 뺀다.

선택지를 추천안과 함께 보여 주고 고르게 한다. 고르지 않은 항목은 바꾸지 않는다.

## 7. 검수 체크리스트 (스냅 시트를 보면서)

- [ ] 글자·패널이 화면 밖(특히 오른쪽 1880 이후)으로 잘리지 않는다
- [ ] 라벨끼리, 라벨과 곡선·화살표가 겹치지 않는다(지시선이 글자를 관통하지 않는다)
- [ ] 자막 두 개가 동시에 보이지 않는다
- [ ] 스텝 경계(정수 위치)에서 요소가 갑자기 튀거나 사라지지 않는다 → `x.0`, `x.5`, `x+1`을 같이 본다
- [ ] 장면 전환 구간(다음 장면 첫 스텝의 0.2~0.4)에서 두 장면이 어색하게 겹치지 않는다
- [ ] 3D 블록 줌·회전 중간 프레임에서 블록이 엉뚱한 곳으로 튀지 않는다
- [ ] 최종 상태(스텝 끝)만 봐도 그 스텝의 요점이 읽힌다(PPT에서는 마지막 프레임으로 멈춰 있으므로)
